# Project-2Virosto Restaurant

A modern, responsive web application designed for Virosto Restaurant. This platform allows customers to explore the menu, learn about the restaurant's history, register an account, make food purchases, and easily find location and delivery information.

Live Demo: Virosto Restaurant Website


📝 Project Description

Virosto Restaurant provides a simple and user-friendly digital experience for restaurant patrons. Visitors can browse dedicated sections for different menu items, calculate total receipt costs upon order selection, learn about the restaurant's origin, create an account, and get full delivery details.

✨ Features

Comprehensive Navigation: Dedicated pages for Pizza, Pasta, and other menu categories.

Interactive Cart & Receipt: Calculates and displays the running total of your order receipt.

User Registration & Ordering: Allows users to register an account and place online food orders (SUSPENDED)

Informative Homepage: Central hub featuring restaurant history (suspended), location details, and delivery options (suspended).

Responsive Design: Optimized for smooth browsing across desktop and mobile devices.

🛠️ Technologies Used

HTML5: Structure and markup of the web application.

CSS3: Custom styles, layouts, and visual design.

JavaScript (ES6): Dynamic features, price calculation, page interactions.

Usage 

Open the link : https://nabilsoulaymann-tech.github.io/Project-2/ and you will find 4 pages (one is suspended)
